❄ 寒冰变声器

把任意音频叠上 N 层 Scratch / TurboWarp「机械」音效，并可不变速升/降调 —— 寒冰动画同款搞笑特效

🔍 校验上游算法 (Scratch robot-effect.js) 核心库 v2.0.0

1 导入音频

拖入音频文件 或 点击选择（支持 WAV / MP3 / OGG / M4A）
导入后仅在本机处理，不会上传任何服务器
尚未导入音频

2 寒冰特效参数

层数越高，机械/冰冷感越强。1 层已明显，3~6 层是日常搞笑档，10+ 层非常夸张。
0 = 原调。正数升调、负数降调，时长不变（相位声码器）。

4 本地工作区缓存与备份

推荐工作区：把本工具文件夹放到任意本地目录（例如 D:\ice-voice 或移动硬盘）
点「连接工作区」选择一个目录（建议选 E 盘目录）后，每次处理的结果会自动保存到此目录下的 输出/ 子目录，并额外备份一份到 backups/。
未连接工作区时，「自动下载」会落到浏览器默认下载目录（通常是 C 盘）；连接 E 盘工作区后可避免往系统盘写大文件。需要 Chromium 内核浏览器（Edge / Chrome）。

5 给开发者 / AI 的接入方式

本工具的核心算法全部封装在 js/ice-voice-core.js（UMD，浏览器与 Node 通用）。 把它当成「AI 变声插件之后的特效插件」即可：拿到任意 AudioBuffer / WAV 数据 → 调 IceVoice.transformBuffer / transformChannels → 得到寒冰版。
浏览器中调用（点击展开） 
// 1) 引入核心库 <script src="js/ice-voice-core.js"></script>
const out = await IceVoice.transformBuffer(audioBuffer, {
  layers: 3,            // 寒冰层数 N
  pitchSemitones: 5,    // 升 5 半音，不变速；0 = 不变调
  order: 'pitch-first', // 'pitch-first' | 'ice-first'
  engine: 'auto'        // 'webaudio'(浏览器) | 'js' | 'auto'
});
// out 是 AudioBuffer，可直接播放或 encodeWav 导出
Node.js 中调用（点击展开） 
const IceVoice = require('./js/ice-voice-core.js');
const fs = require('fs');
const wav = fs.readFileSync('in.wav');
const audio = IceVoice.decodeWav(wav.buffer.slice(wav.byteOffset, wav.byteOffset + wav.byteLength));
const res = IceVoice.transformChannels(audio, { layers: 4, pitchSemitones: -3 });
fs.writeFileSync('out.wav', Buffer.from(IceVoice.encodeWav(res, 16)));
