❄ 寒冰变声器

把任意音频叠上 N 层 Scratch / TurboWarp「机械」音效，并可不变速升/降调 —— 寒冰动画同款搞笑特效

🔍 校验上游算法 (Scratch robot-effect.js) 核心库 v2.1.0

1 导入音频

拖入音频文件 或 点击选择（支持 WAV / MP3 / OGG / M4A）
导入后仅在本机处理，不会上传任何服务器
尚未导入音频

2 寒冰特效序列

「＋变调」按钮使用的半音值：
顺序就是指令的先后：写在前面的先做，写在后面的后做，一步都省不掉、也不会自动重排。
例：机械，机械，变调(-12) = 先叠 2 层机械、再降 12 半音 · 变调(-12)，机械 = 先降 12 半音、再叠 1 层机械（听感不同）· 机械可带载波频率：机械(50)。
逗号中英文都行，多打的空逗号会被自动忽略。
取消勾选后，变调会同时改变音高与速度（似松鼠/慢放效果）。

5 给开发者 / AI 的接入方式

核心算法封装在 js/ice-voice-core.js（UMD，浏览器与 Node 通用）。 支持两种调用：transformChannels（{channels,sampleRate} 格式）与 transformScript（指令脚本序列），以及浏览器专用的 transformBuffer（AudioBuffer）。
浏览器中调用（点击展开） 
// 引入核心库 <script src="js/ice-voice-core.js"></script>
// 序列式：机械×2 → 降 5 半音 → 机械 → 降 7 半音（不变速）
const res = IceVoice.transformScript('机械，机械，变调(-5)，机械，变调(-7)', {
  channels: IceVoice.audioBufferToChannels(audioBuffer),
  sampleRate: audioBuffer.sampleRate
}, { preserveDuration: true, normalize: true });
// res = { channels:Float32Array[], sampleRate }，可编码 WAV 或转回 AudioBuffer
Node.js 中调用（点击展开） 
const IceVoice = require('./js/ice-voice-core.js');
const fs = require('fs');
const wav = fs.readFileSync('in.wav');
const audio = IceVoice.decodeWav(wav.buffer.slice(wav.byteOffset, wav.byteOffset + wav.byteLength));
// 解析与执行指令脚本
const res = IceVoice.transformScript('机械，变调(-12)，机械', audio, { preserveDuration:true });
fs.writeFileSync('out.wav', Buffer.from(IceVoice.encodeWav(res, 16)));
